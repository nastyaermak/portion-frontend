# Порція — фронтенд

Проста сторінка для сайту рецептів «Порція»: отримує список рецептів з бекенду через REST API і показує їх з КБЖВ на порцію. Зроблено на HTML + jQuery, щоб показати, що фронтенд на іншому порту отримує дані з API (CORS).

Бекенд: https://github.com/nastyaermak/portion

## Як запустити проєкт

| Що | Адреса |
|---|---|
| Бекенд (Django) | http://127.0.0.1:8000, API — http://127.0.0.1:8000/api |
| Фронтенд | http://localhost:5500 |

1. Запустіть бекенд за інструкцією з його README (порт 8000).
2. У папці фронтенду запустіть простий сервер на порту 5500:

   ```bash
   python3 -m http.server 5500
   ```

3. Відкрийте http://localhost:5500 — з'явиться список рецептів.

Адреса API задається на початку скрипта в `index.html` (`API_URL`). Бекенд дозволяє запити (CORS) з `http://localhost:5500` і `http://127.0.0.1:5500`.
